如何升级

  1. 先保存作品，建议导出一份 .mwb 便携工程作为备份。
  2. 在 GitHub 发布页下载新版 Setup-x64.exe，核对文件名、版本与 SHA-256。安装器目前未签名。
  3. 关闭 Music Workbench，再运行安装器，使用原来的程序目录。作品目录与程序目录分开保存。
  4. 重新打开软件；AI 工具包无需重复下载。若新版调整了模型依赖，请在 AI 工具管理中检查或修复。

这是手动更新入口；软件不会在后台下载更新。打开本页不会连接 GitHub。
