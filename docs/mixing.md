# 从草稿到混音

[English](mixing.en.md) · [制作工作台](create-preview.md)

使用实时轨道效果和可选的主输出峰值限制处理混音。无需下载神经模型，原始音频保留。

![效果器与多轨编排](images/create-effects-zh.png)

## 先完成一段混音

1. 打开工程，点击混音台某轨的 **FX**，或切到下方 **效果器** 页选择轨道。
2. 选择「清晰人声、温暖键盘、紧实鼓组、氛围空间」预设，按播放试听。
3. 根据需要打开/关闭均衡、压缩、混响，调整参数。轨道推子和声像位于效果器之后。
4. 用 **A/B 原声** 比较该轨的处理前后；旁路不改变轨道音量和主输出限制。重置、参数和旁路均自动保存并可撤销。
5. 在主输出卡片开启峰值限制。用较小的增益衰减保护峰值，不要靠大幅限制补救过载的混音。
6. 导出 WAV，得到含全部轨道效果和尾音的 24-bit/44.1 kHz 立体声混音。MIDI 文件只含音符等数据，不包含音频效果。

A/B 不自动匹配响度；音量更大不代表音色更好。旧工程的新增效果默认关闭，不会自动改变已有声音。
预设是可修改的起点，不是按素材自动优化的 AI 母带。

## 信号链与参数

`片段/乐器 → 片段增益与淡化 → EQ → 压缩 → 混响 → 轨道音量与左右平衡 → 求和 → 主推子 → 限制器`

| 模块 | 当前实现 |
| --- | --- |
| EQ | RBJ 二阶滤波器；150 Hz 低架、1 kHz 钟形、4 kHz 高架，各 ±12 dB；中频 Q=√½ |
| 压缩 | 立体声联动峰值检测、硬拐点；阈值、压缩比、起音、释放和手动补偿；无自动补偿或侧链输入 |
| 混响 | 四个并联反馈梳状滤波器、两个串联全通，左右延迟略不同；湿声 0–50%，反馈标称衰减 0.2–3 s |
| 主输出限制 | 可选立体声联动、瞬时采样峰值起音和指数释放；上限 −12 到 −0.1 dBFS，默认 −1 dBFS |

限制器**不是 True Peak / 真峰值限制器**，不做过采样或前瞻；大幅限制会产生失真。
混响导出尾部按标称衰减时间加 0.1 秒保留；EQ 至少留 0.15 秒衰减区间。
当前内置效果器使用固定顺序；可重排插件链、总线/发送、效果参数自动化、VST 和完整母带处理尚未提供。片段音量曲线见 [音量与过渡](volume-and-repaint.md)。

## 播放、导出与当前边界

浏览器 AudioWorklet 在音频线程运行效果，Python 用 NumPy/SciPy 分块导出，二者使用相同公式、延迟长度和信号顺序。
实时参数更新向已有处理器发消息，不重新抓取、解码或建立音频源；A/B 使用 15 ms 过渡。
暂停时显式销毁处理器，避免已断开音频图的工作线程继续处理。

从头开始、固定参数的播放与导出已做数值验证；WAV 另含 24-bit 量化，浏览器音频图使用 Float32。
**定位/暂停恢复会重新建立滤波、压缩和混响状态**，不预渲染定位点之前的声音；起点附近可能与从头连续播放不同，定位到纯尾音区间可能静音。
循环复用效果器，尾音会延续至下一轮；源素材在边界不连续时仍可能产生杂音，详见 [循环说明](timing.md)。播放时的临时效果调参不录成自动化，也不会作为时间曲线导出。
AudioWorklet 需要现代浏览器与 localhost/HTTPS；效果器加载失败会提示并停止播放，不静默跳过处理。
32 轨是工程上限，不保证任意设备能实时运行 32 轨全部效果。

关闭限制器后仍沿用削波导出保护：超出 0 dBFS 时拒绝 WAV，并提示降低主推子。
播放中的主输出卡片显示实际采样峰值和过载提示；增益衰减读数是近期音频块读数，不是长时最大值。

[技术验证 / Technical verification](feature-validation.md)。

算法参考：[W3C Audio EQ Cookbook](https://webaudio.github.io/Audio-EQ-Cookbook/audio-eq-cookbook.html) 中的 RBJ 系数公式；混响采用经典 Schroeder 结构。实现位于 `studio/effects.py` 和 `ui/static/effects-dsp.js`，跨语言回归位于 `tests/test_mix_effects.py`。
