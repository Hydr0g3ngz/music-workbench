# 钢琴专用转录：Transkun

[English](piano-notes.en.md) · [音符整理](note-editing.md)

从首页 **AI 工具管理 → 钢琴多音音符** 安装独立环境。安装器下载并校验官方 Transkun 2.0.1 源码、V2 权重和配置；仅安装推理依赖，不需要训练所用的本地编译器。安装完成会用内置钢琴片段执行真实离线转录，通过后才启用。

选择独奏钢琴片段，在模型面板运行 **钢琴 → 可编辑多音 MIDI**。结果包含音符 JSON、MIDI 和合成试听；点 **音符加入乐器轨** 后可编辑、换音色、整理声部，再随工程导出。

## 电脑要求与精度

- Windows x64；自动配置使用 Torch 2.10 / CUDA 12.8、FP32，未量化。
- 安装检查要求 Turing 或更新的 NVIDIA GPU，至少 4 GB 总显存和兼容驱动；运行前另检查约 2 GB 空闲显存。可显式选择 CPU，但仍使用同一工具包，其下载不等于轻量 CPU 包。
- 预计下载约 3–5 GB，预留 10 GB 磁盘。权重约 56 MB；运行环境远大于权重。
- 本机 RTX 4070 Laptop 8 GB 的 16 秒钢琴片段：模型调用约 10.8 秒、完整调用约 18.3 秒、Torch 峰值约 904 MiB。含加载开销；显存数字不含 CUDA 上下文，也不是最低硬件承诺。

Basic Pitch 仍适合不想安装 Torch 的用户，以及其他单件乐器。根据素材选择模型；[钢琴评测](../benchmarks/reports/piano-v1.json)只覆盖三首曲子的六个片段，不是所有风格的排名。

## 结果边界

Transkun 只针对钢琴。当前采用 V2 默认的按键松开时刻，不把延音踏板 CC64 展开成持续音；踏板控制不进入钢琴卷帘。力度是估计值。上游不提供经过校准的逐音置信度，音符 JSON 的 `score=0` 表示不可用，不表示“确定错误”。

不能把完整混音丢进去就期待准确总谱。合成钢琴、强混响、特殊演奏和生成音频的泛化效果需试听核对。权重与配置经过固定 SHA-256 校验；代码及权重来自[官方仓库](https://github.com/Yujia-Yan/Transkun)，按其 MIT 许可使用。
