# 可选示例工程 / Optional example projects

第一次使用不需要额外下载：安装后在首页选择 **跟着做出第一段音乐**，即可创建八小节示例。

No extra download is needed for the first lesson. Choose **Make your first musical sketch** on Home.

[**下载示例工程包 / Download example projects**](https://github.com/Hydr0g3ngz/music-workbench/releases/download/v0.2.0.dev21/Music-Workbench-Examples.zip)

## 包含什么 / Contents

| 工程 / Project | 可以学到什么 / Explore |
| --- | --- |
| First Sketch | 八小节、四层声音，适合试听、改音符与混音入门 / Eight bars and four layers for first edits |
| 雨后的街灯 / After the Rain | AI 钢琴、可编辑的马林巴回声、参考变奏和共享效果 / Piano, editable echoes, a variation and shared effects |
| 窗灯 / Windowlight | 留白、分组复制、段落对比和结尾收束 / Space, groups, contrast and a quiet ending |

本包适用于 dev21 或更新版本。Use dev21 or newer for these projects.

## 打开工程 / Open a project

1. 解压后，在软件 **工程** 页面选择恢复/导入 `.mwb`，选择一个示例。
2. 恢复为独立工程后，先播放，再尝试静音、独奏、修改音符或调整效果。
3. 导出 WAV 得到完整声音；导出 MIDI 保存可编辑乐器音符；导出 MWB 保留音频和编排。

Unzip, restore an `.mwb` from **Projects**, then play and edit the new project. Export WAV for the full sound, MIDI for editable notes, or MWB to keep the arrangement and audio.

已有音频和音符已包含在工程中，播放和编辑不要求下载 AI 模型；重新生成或重新转录才需要相应模型。示例的素材署名随包附带，也可以在软件内导出。生成结果因模型、硬件与设置而异。

Audio and notes are included. Playback and editing need no AI download; regeneration or retranscription needs the relevant model. Credits are included and can be exported from the app. New model outputs can differ.
