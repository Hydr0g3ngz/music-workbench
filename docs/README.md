# Music Workbench 使用指南

[English](README.en.md) · [返回首页](../README.md)

## 第一次使用

1. [下载并安装](windows-install.md)，从桌面或开始菜单打开软件。
2. 首页选择 **跟着做出第一段音乐**，用 [五步教程](first-sketch.md) 完成试听、改音符、混音和导出。
3. 想了解全部控件，打开 [工作台指南](create-preview.md)；想拆开一个现成作品，下载 [可选示例工程](examples.md)。

基础创作无需 AI 模型。需要本地 AI 时，再按 [模型与硬件要求](models.md) 安装相应工具。
