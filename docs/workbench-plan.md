# Music Workbench 平台设计

[English](workbench-plan.en.md) · [路线图](workbench-roadmap.md) · [模型候选](local-model-candidates.md)

本文面向平台与后端贡献者。当前功能与限制以 [使用指南](create-preview.md) 为准；表中的规划不代表已实现。

Workbench 与 Studio 分别维护创作和整曲分析；公开入口、数据位置与旧格式兼容见[产品边界](product-boundaries.md)。模型接入应服务于可继续编辑、编排和混音的作品素材。

## 产品与工程目标

在本地完成创作、编曲、录音、编辑、混音和导出。初学者通过模板、预设、跟练和可撤销操作入门；专业参数逐层展开。AI 输出成为可继续编辑的工程素材。Agent 后续复用工程命令，不作为基础创作的前置条件。

| 领域 | 已有基础 | 扩展方向 |
| --- | --- | --- |
| 编排 | 音频/MIDI 轨、片段源区间与位置、切分/复制、循环、段落 | 成组移动、局部时间校准、更长工程 |
| 乐器与 MIDI | 内置采样与合成、鼓点、导入、钢琴卷帘与批量编辑 | 更多采样、控制事件、第三方乐器 |
| 录音 | 单声道采集、设备/电平、试听后入轨 | 同步叠录、监听、预备拍与延迟补偿 |
| 混音 | 推子/声像、固定顺序 EQ/压缩/混响、音量曲线与交叉淡化 | 总线、发送、效果自动化与插件宿主 |
| AI 素材 | ACE-Step、分轨、单旋律 MIDI、来源与任务记录 | 多音转谱、歌声、音色转换、音效、检索与音乐修复 |
| 交付 | WAV/MIDI、署名、MWB 便携工程 | 任务配方携带、依赖诊断与批量交付 |
| 上手 | Windows 安装器、独立窗口、ACE-Step 自动配置与双语跟练 | 更广硬件覆盖与目标用户可用性验证 |

## 工程表示与完整性

制作工程采用轨道与片段结构；音频素材独立保存，片段引用源区间与工程位置，MIDI 保存音符。秒、拍、小节、采样与 MIDI tick 必须显式换算。当前固定 4/4；速度图与拍号变化属于后续设计。

SQLite 保存工程版本、素材引用、任务与历史，大文件存磁盘。保存与采用检查乐观版本，原素材不可变；失败保留可恢复状态。MWB 打包当前编排、音频和署名，不含权重、环境与完整任务数据库。不兼容变更需迁移方案、历史兼容与往返验证。

## 播放、渲染与进程

Web Audio transport 统一调度试听，后台任务与界面刷新不重建正在播放的音源。实时处理在 AudioWorklet 中运行，离线渲染使用共享语义的 Python DSP。比较效果顺序、尾音、采样率与片段边界；定位后状态重建与连续播放的差异必须记录。

控制服务、播放/渲染和模型 worker 分离，避免推理阻塞播放。模型使用隔离环境与可取消子进程。低延迟录音、设备驱动与插件宿主需单独验证，浏览器基本播放不能代替原生设备测量。

## 后端接入契约

| 部分 | 必要内容 |
| --- | --- |
| 描述 | 稳定 provider ID、能力、双语参数、版本、维护状态、代码/权重/声库许可 |
| 输入 | 按能力接收文字、音频、MIDI、歌词、选区与音乐条件；明确源时间与工程时间 |
| 运行 | 固定依赖、独立环境、设备/精度/offload、资源估计与实测、进度和取消 |
| 输出 | 有类型素材、时间基准、输入哈希、参数、seed、源码/权重修订与文件哈希 |
| 采用 | 明确目标位置与对齐方式，检查源版本，支持试听、撤销、重开和导出 |
| 失败 | 清楚诊断、无半份发布、可重试、中断任务有明确状态 |

环境可用、权重已下载、推理完成与质量已测是不同状态。不同模型不得被迫共用不兼容 Torch/Transformers。CPU、8 GB、12–16 GB、24 GB+ 档位需实测后声明，参数量不是全管线显存预算。

## 评测与发布

工程评测覆盖操作、历史、播放/导出一致、内存与恢复。模型分任务测质量，不把歌词、分轨、音符和生成合成总分；训练重叠、失败与逐例退步必须公开。

- 分轨：真值 SI-SDR、对齐、泄漏、瞬态与资源。
- 转谱/节奏：起音、音高、止音 F1、八度错误、节拍/强拍与人工修改量。
- 生成：固定提示/seed、音乐条件、参考保留、片段衔接、候选选择成本与盲听。
- 修复/效果：干净对照、失真、音乐保真、响度匹配、实时/离线一致。
- 所有后端：冷/热时间、RAM/VRAM、长输入、离线、取消与失败恢复。

核心要求是完整制作路径：从想法或导入素材开始，经编辑、混音、保存、导出，再到新工作区恢复。单独生成一个文件不能验证其余工程能力。具体优先级见 [当前路线图](workbench-roadmap.md)，复现入口见 [技术参考](technical-reference.md)。
