# 工作台使用指南

[English](create-preview.en.md) · [文档目录](README.md)

![音乐制作工作台](images/create-workbench-zh.png)

安装后从首页打开示例、新建工程或导入素材。第一次使用建议选择 [五步跟练](first-sketch.md)。源码启动见 [快速开始](../QUICKSTART.md)。

## 认识界面

| 区域 | 常用操作 |
| --- | --- |
| 顶部播放栏 | 播放、暂停、停止、定位、BPM、循环、节拍器与录音；空格切换播放 |
| 左侧素材与乐器 | 导入音频/MIDI，搜索、试听并加入音色、鼓点与素材 |
| 中间编排 | 移动、裁切、切分、复制音频或 MIDI 片段；吸附与缩放；段落标记和范围复制 |
| 下方面板 | 混音台、效果器、钢琴卷帘；可拖动、拉长、多选和批量修改音符 |
| 右侧检查器 | 修改名称、位置、源偏移、时长、增益、淡变与音色 |
| AI 模型与处理任务 | 配置、排队、取消、试听候选；明确采用后才改变工程 |
| 工程菜单 | 新建、重开、重命名、删除与恢复、撤销/重做、便携工程恢复 |

## 从素材到作品

1. 从「乐器」选一个音色，或导入自己的音频/MIDI。[音色与 MIDI](creation-library.md)
2. 双击 MIDI 片段编辑音符；用循环反复听一段，尝试改变节奏或旋律。[循环与节拍器](timing.md)
3. 使用段落标记与跨轨范围复制扩展结构。[创作蓝图](arranging-methods.md)
4. 在混音台调整各轨音量、声像与效果；用曲线、淡变衔接片段。[混音](mixing.md) · [过渡](volume-and-repaint.md)
5. 保存可编辑工程，导出一份音频试听。

原始素材在剪辑后仍保留。移除片段或轨道可撤销；删除工程后可从回收站恢复。后台任务完成后不会自动替换编排或切换试听音轨。

## 保存与导出

工程会自动保存，撤销/重做历史随工程保留。如果另一个窗口已修改同一工程，请先刷新当前版本，再继续编辑。

| 格式 | 用途 |
| --- | --- |
| WAV | 44.1 kHz、24-bit 立体声音频，包含混音与效果器尾音；用于播放和分享 |
| MIDI | 乐器轨音符；不包含音频轨或音频效果，也不会自动为整首音频转谱 |
| 便携工程 `.mwb` | 编排、音频与来源署名；通过「工程 → 恢复便携工程」在其他工作区继续编辑 |
| JSON 快照 | 本地编排记录，引用素材路径；单独复制不能替代 MWB 备份 |

MWB 不包含模型权重、独立环境或完整任务数据库。使用同一软件版本恢复可减少采样与 DSP 差异。WAV/MIDI 导出完整编排，不包含节拍器或循环重复。关闭峰值限制时，过载导出会提示降低主音量。

## 加入本地 AI

可从空工程生成草稿，也可选择音频片段进行分轨、单旋律 MIDI 提取或素材适配。先试听候选，再选择加入播放头或对齐替换；采用支持撤销。[支持模型与安装](models.md) · [AI 制作流程](ai-production-workflow.md)

## 当前限制

- 固定 4/4、44.1 kHz 立体声，最多 32 轨、10 分钟；单文件上传最多 256 MiB，解码/合成试听预算 256 MiB。
- 改 BPM 会改变网格与 MIDI，音频不会自动拉伸；需要单独制作 [对拍候选](material-fitting.md)。
- 当前支持内置采样/合成音色与固定顺序效果器；已支持总线与发送。通用 SFZ/SoundFont 和 VST 尚未提供。
- 片段音量曲线可随时间变化；实时调效果参数不会录成自动化。
- 录音需先暂停编排，无同步叠录、输入监听或延迟补偿。
- 定位/暂停恢复会重建效果状态；循环会保留效果器尾音。源波形在边界不连续可能产生杂音。
- 模型的输入范围因任务而异：工作台工具只处理选中的片段，参考生成/重绘按其面板指定范围取样。
