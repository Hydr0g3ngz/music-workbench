# v0.2.0.dev5 — Separation into arrangement / 分轨进入编排

> 历史版本 / Historical build：本页描述拆分前的 Music Studio/Next/Create，非当前 Workbench 安装说明。See the [current release](https://github.com/Hydr0g3ngz/music-workbench/releases/tag/v0.2.0.dev14) for the Windows installer and supported features.

Create now connects local music separation to arrangement: select an audio clip, separate,
audition vocals/backing, then replace the original clip with both aligned tracks in one undoable edit.
Position, source trim, gain and fades are retained. Originals remain available; duplicate replacement,
changed clips, damaged outputs and partial stem sets are rejected. Individual results insert at the playhead.

新增可选 Mel-Band RoFormer KJ 独立环境。先试听再替换原片段，分轨对齐进入同一工程，
支持一次撤销、重做和继续混音导出。任务列表刷新不重载试听音频；安装操作与离线推理分开。
Demucs、经典版、Next 和已有工程保留，不会自动重新分析或替换旧结果。

## Measured / 实测

- Two frozen MUSDB7 previews: vocal SI-SDR 13.30/13.99 dB versus Demucs 10.74/11.16 dB.
- Approx. 2003 MiB Torch allocator peak on RTX 4070 Laptop 8 GB; excludes CUDA context and other processes.
- Complete bundled 45 s licensed song: processing 25.2 s, 2040 MiB Torch peak; real browser audition/adoption/Undo/Redo checked.
- A 30 s trimmed arrangement export reconstructs the original-clip export within `1.20e-7` maximum sample difference.
- 133 Python tests and 37 Node checks passed, including corruption/conflict/undo and audition refresh regressions.
- This is a small regression comparison, not a full MUSDB or general SOTA claim; no blind listening study.

## Setup / 安装

Python 3.11/3.12 required. ZIP is source plus wheel, not a standalone EXE.
Run `python scripts/setup_separation.py` for the optional model. Setup downloads pinned MIT source,
a model-card-MIT checkpoint (~913 MB) and a separate inference runtime. Neither weights nor Python/CUDA are bundled.
No model download occurs on startup/inference. CPU setup is documented; GPU measurements are Windows only.

[中文指南](../separation.md) · [English guide](../separation.en.md)

Known limits: two stems only; whole-asset processing, ten minutes maximum; residual backing is not perfect isolation.
Nonlinear effects copied to separate tracks can change the combined sound. Recording, buses, automation,
multi-instrument separation and deep Agent arrangement control remain future work.
