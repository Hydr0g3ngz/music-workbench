# Music Workbench 0.2.0.dev6 · Local recording / 本地录音

The independent workstation lives at https://github.com/Hydr0g3ngz/music-workbench. The original song analysis product remains at https://github.com/Hydr0g3ngz/music-studio.

新增单声道本地录音：设备选择与输入电平 → 录制 → 试听或 WAV 下载 → 从播放头加入新音轨。停止/取消释放设备，保存失败保留录音；同一 take 重试不重复入轨，支持撤销、重开和导出。

Record mono PCM WAV locally, select input and check levels, audition before adding a track at the playhead, or download the take. Stop/cancel release devices. Failed saves retain audio; retry is idempotent. History, reopen and export use the arrangement engine.

Windows: install Python 3.11/3.12 and run Start-Music-Workbench.cmd. ZIP contains source and wheel, not a standalone executable. Models are optional; weights are not bundled. Default port 8920 and outputs/workbench directory are independent from Music Studio.

Synchronized overdubbing, monitoring, count-in, latency compensation and multichannel capture are not available. Pending takes live in page memory: add or download before leaving.

Validation includes deterministic capture/lifecycle tests, API history/export tests and Chrome with synthetic input. This is not a hardware latency or microphone quality evaluation.
