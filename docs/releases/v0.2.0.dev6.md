# Music Workbench v0.2.0.dev6 · 本地录音 / Local recording

历史源码预览版，需 Python 3.11/3.12。需要直接安装的软件，请下载 [当前 Windows 安装器](https://github.com/Hydr0g3ngz/music-workbench/releases/tag/v0.2.0.dev21)。

This older source preview requires Python. For an installable app, use the current Windows release above.

选择输入、查看电平、录音和试听，再从播放头加入新音轨。Choose an input, check levels, record and audition, then add the take at the playhead.

[下载本版源码包 / Source package](https://github.com/Hydr0g3ngz/music-workbench/releases/download/v0.2.0.dev6/Music-Workbench-0.2.0.dev6-Windows.zip) · [校验文件 / Checksums](https://github.com/Hydr0g3ngz/music-workbench/releases/download/v0.2.0.dev6/SHA256SUMS.txt)

解压后安装依赖，运行 `Start-Music-Workbench.cmd`。模型和权重需要另行安装。作品默认保存在 `outputs/workbench`。录音没有同步叠录或延迟补偿；离开页面前应保留未采用的录音。

Extract, install the dependencies and run `Start-Music-Workbench.cmd`. Models are separate. Projects default to `outputs/workbench`. Keep pending recordings before leaving; synchronized overdubbing and latency compensation are unavailable.
