# Music Workbench 0.2.0.dev7 · Loop and metronome / 循环与节拍器

Repeat a selected section while building an arrangement. Set a loop in bars, use the selected clip or the full arrangement, and see its range on the ruler. Add a live metronome with adjustable volume and first-beat accent. Settings persist with undo/redo.

新增自定义循环小节、所选片段/完整编排快捷设置和标尺区间显示，以及可调音量和重拍的节拍器。设置随工程保存、撤销与重做，旧工程保持兼容。循环按音频时钟预排程，复用缓存与效果器，避免逐轮重载。

WAV/MIDI export the full arrangement, without loop repetitions or metronome clicks. The metronome is for monitoring; this release does not add synchronized overdubbing, count-in or latency calibration. Long browser stalls can still interrupt playback.

Windows: Python 3.11/3.12 + Start-Music-Workbench.cmd. Source/wheel ZIP, not a standalone EXE. Optional models and weights remain separately installed. Existing workspaces and the original Music Studio product are preserved.

Guides: [中文](https://github.com/Hydr0g3ngz/music-workbench/blob/main/docs/timing.md) / [English](https://github.com/Hydr0g3ngz/music-workbench/blob/main/docs/timing.en.md).

Validation: 149 Python / 52 Node tests, Ruff, installed wheel without neural models and real browser checks. [Evidence and limits](https://github.com/Hydr0g3ngz/music-workbench/blob/main/docs/timing-validation.md).
