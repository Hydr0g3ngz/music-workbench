# Music Workbench 0.2.0.dev14 · First sketch / 第一段音乐

这次从 dev7 公开版升级到完整 Windows 安装预览：双击安装、独立软件窗口、五步创作跟练、图形化本地 AI 配置，以及多轮编排与混音改进。作品和模型存放在程序目录之外，升级保留。

From the previous dev7 public release: a Windows installer, a dedicated app window, five guided creation steps, graphical local-AI setup, and arrangement/mixing improvements. Projects and models remain outside the program directory and survive upgrades.

## 下载与开始 / Download and start

1. Windows 10 22H2 / 11 x64：下载 **Music-Workbench-0.2.0.dev14-Setup-x64.exe**，安装后从桌面或开始菜单打开。基础创作自带运行时，无需配置 Python。
2. 首页选 **跟着做出第一段音乐 / Make your first musical sketch**。试听 → 分层 → 改一个音 → 混音 → 导出，约 5–10 分钟。教程中英双语，按工程保存进度，支持关闭后继续和明确跳过。
3. WAV 用来播放、分享；MWB 用来保留可编辑工程与音频。**First-Sketch-Example.mwb** 是本次真实跟练后导出的示例，可从工程面板恢复。
4. **Music-Workbench-First-Sketch-Demo.mp4** 是 36 秒实际界面截图剪辑，配示例导出音频；不是连续实时录屏或 AI 生成速度演示。

Install the x64 Setup executable, then follow the five in-app steps. No system Python or model download is required for the basic lesson. WAV is playable audio; MWB preserves editable work. The 36-second MP4 combines actual UI screenshots with exported example accompaniment, rather than showing real-time generation.

源码 ZIP、wheel、sdist 供开发者使用；普通用户选择 Setup。所有附件可用 **SHA256SUMS.txt** 校验。[入门教程](https://github.com/Hydr0g3ngz/music-workbench/blob/main/docs/first-sketch.md) · [安装说明](https://github.com/Hydr0g3ngz/music-workbench/blob/main/docs/windows-install.md)。

## 本次新增 / Included changes

- Windows 单窗口安装体验、PerMonitorV2 显示、页面缩放恢复与诊断、更清楚的文字与高像素密度波形。
- ACE-Step 软件内自动配置：硬件与磁盘检查、独立 Python/CUDA 环境、固定模型校验、暂停恢复、实际 12 秒生成成功后再启用。
- 创作蓝图、段落与能量、结构草案、工程上下文提示词；MIDI 多选/量化/力度、段落复制与便携工程。
- 素材对拍与等响度候选 A/B；音量曲线、交叉淡化、选区外保持的 AI 局部重绘。
- 五步入门与离线手册，真实操作记录、明确跳过、每工程独立进度。保留本地录音、循环、节拍器、效果器与导出。

Includes the installer and DPI fixes, isolated ACE-Step setup, composition briefs/sections, MIDI editing, portable projects, beat fitting, matched A/B, volume curves/crossfades, region repaint and the new beginner lesson.

## 验收与边界 / Validation and limits

179 Python tests、76 UI tests；真实界面五步跟练、WAV/MWB 导出、中文/English 切换、进度恢复与不同窗口宽度验证。上一轮已验收安装、升级、卸载后作品与模型保留，及独立环境实际 AI 推理；本版沿用同一安装机制并补测打包资源。

Local validation includes 179 Python and 76 UI tests, the real five-step workflow, exports, language switching and lesson recovery. The prior build verified install/upgrade/uninstall retention and actual inference through the isolated AI environment; this build retains that installer mechanism and verifies its packaged lesson resources.

- 开发预览，安装器未签名；尚无自动更新器。
- 基础创作无需 AI。自动环境首批仅 ACE-Step：兼容 NVIDIA ≥8 GB 显存、35 GB 空间、首次约 8–12 GB 下载。其他模型仍需各自配置，不能承诺所有开源模型都已接入。
- 缺少 WebView2 的全新虚拟机、其他显卡/物理 DPI 缩放、受限网络和真正零基础用户仍需扩大验收。AI 大权重本轮验证复用校验缓存。
- 当前并非完整专业 DAW；无盲听质量结论。原歌曲分析项目 [Music Studio](https://github.com/Hydr0g3ngz/music-studio) 独立保留。

Unsigned development preview with no automatic updater. ACE-Step is the first automatic AI profile; other models require their own setup. A clean VM without WebView2, additional hardware/display scales, restricted networks and novice usability still need broader testing.
