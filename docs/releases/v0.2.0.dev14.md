# Music Workbench 0.2.0.dev14 · Your first sketch / 第一段音乐

安装后跟着五步提示，试听音轨、修改音符、调整混音并导出第一段音乐。基础创作自带运行环境，无需配置 Python 或下载 AI 模型。

Install and follow five in-app steps to listen, edit a note, balance the mix and export your first sketch. The basic runtime is included; no Python setup or AI download is required for the lesson.

## 下载与开始 / Download and start

1. **Windows 10 22H2 / 11 x64**：下载 [Music-Workbench-0.2.0.dev14-Setup-x64.exe](https://github.com/Hydr0g3ngz/music-workbench/releases/download/v0.2.0.dev14/Music-Workbench-0.2.0.dev14-Setup-x64.exe)，安装后从桌面或开始菜单打开。
2. 首页选择 **跟着做出第一段音乐 / Make your first musical sketch**，约需 5–10 分钟。教程支持中英切换、关闭后继续、跳过与重新学习。
3. 导出 WAV 分享音频；导出 MWB 保留编排与音频，便于继续制作。

Download the Setup executable, install and open Music Workbench. Choose **Make your first musical sketch** on Home. Save audio as WAV, and keep an editable copy as MWB. Source ZIP, wheel and sdist are for developers.

## 新功能 / What's included

- **更容易上手**：五步双语跟练、离线手册、每工程独立学习进度。Bilingual lesson, offline handbook and resumable progress per project.
- **完整 Windows 安装流程**：自带基础运行时、离线 WebView2 前置安装、独立软件窗口、更清楚的文字与高 DPI 波形。Bundled runtime, offline WebView2 prerequisite, dedicated window and sharper display.
- **ACE-Step 自动配置**：检查硬件和空间，准备独立环境、下载校验模型，生成测试通过后启用。Graphical hardware checks, isolated setup, verified downloads and a generation test.
- **更多编排工具**：创作蓝图、段落意图、MIDI 多选/量化/力度、跨轨复制、便携工程。Creative briefs, sections, batch MIDI edits, range copying and portable projects.
- **更顺畅地使用素材**：对拍、等响度候选 A/B、音量曲线、交叉淡化与 AI 局部重绘。Beat fitting, matched candidate A/B, volume curves, crossfades and region repaint.

本地录音、循环、节拍器、EQ/压缩/混响、WAV/MIDI 导出继续可用。保存在程序目录之外的作品与模型可在升级后继续使用；更新前请保存并关闭软件。

Recording, loops, metronome, effects and WAV/MIDI exports remain available. Projects and models are stored separately from the application and retained across upgrades. Save and close the app before updating.

## 要求与限制 / Requirements and limits

- 安装器未签名，暂无自动更新器。Unsigned preview installer; no automatic updater.
- ACE-Step 自动配置需要兼容 NVIDIA 显卡、至少 8 GB 显存、35 GB 可用空间和首次约 8–12 GB 下载；其他模型需分别配置。Automatic ACE-Step setup has these requirements; other models use separate setup guides.
- 当前最多 32 轨、10 分钟、固定 4/4。VST、总线/发送、同步叠录和完整工作台 Agent 操作尚未提供。Up to 32 tracks, ten minutes and fixed 4/4; no VST, buses/sends, synchronized overdubbing or full workstation Agent control yet.
- 硬件、受限网络、不同 DPI 与初学者使用仍需更广测试。模型结果需试听和核对，模型许可独立适用。Broader compatibility/usability testing is ongoing; review model outputs and license terms.

开发者可查阅 [版本测试与评测](https://github.com/Hydr0g3ngz/music-workbench/blob/main/docs/technical-reference.md)。整曲分析产品 [Music Studio](https://github.com/Hydr0g3ngz/music-studio) 独立维护。

Developers can consult [technical reference](https://github.com/Hydr0g3ngz/music-workbench/blob/main/docs/technical-reference.md). Full-song analysis is maintained separately in Music Studio.
