# Music Workbench 0.2.0.dev21

**从 AI 草稿走向可编辑作品 / From an AI draft to an editable piece**

[Windows 下载 / Download](https://github.com/Hydr0g3ngz/music-workbench/releases/tag/v0.2.0.dev21) · [安装与升级 / Install and update](../windows-install.md)

本开发预览版将生成、转音符、声部整理、分组编排、总线混音和工程恢复连成同一流程。可从八小节跟练开始，也可以打开随版提供的《雨后的街灯》工程继续修改。Music Studio 仍是独立的整曲分析项目。

This preview connects generation, editable notes, part simplification, grouped arrangement, bus mixing and project recovery. Start with the eight-bar lesson or edit the included After the Rain project. Music Studio remains a separate full-song analysis product.

## 本版内容 / Changes

- **钢琴专用转录 / Piano transcription**：Transkun 2.0.1 V2 FP32，独立工具包、固定权重校验、真实离线安装验证；支持音符/MIDI/试听与乐器轨编辑。[指南 / Guide](../piano-notes.md) · [六片段评测 / Six-excerpt evaluation](../piano-benchmark.md)。
- **整理与编排 / Editing and arrangement**：音区、力度与起音声部筛选，先试听再应用；多选片段批量音量与淡变，可撤销。[使用方法 / Guide](../note-editing.md)。
- **带入本次公开安装版 / Included since earlier source builds**：Basic Pitch ONNX CPU；分组复制、独立历史、总线/发送、共享湿声混响；七个处理工具包及 ACE-Step 的图形化配置。
- **可靠性 / Reliability**：未变化的任务轮询保留按钮和焦点；保存操作串行；采用结果期间阻止误改旧轨；弹窗重绘后错误提示可恢复；清除 MIDI 选择不再访问已移除片段。
- **升级入口 / Updates**：桌面菜单与首页提供版本、发布链接及手动升级步骤，无后台自动更新器。
- **实际案例 / Case study**：[《雨后的街灯》](../creations/after-the-rain.md)，32 小节、3 轨、2 总线；创作编辑全程普通 UI 操作，导出后恢复并比对内容与 WAV。

## 安装与交付 / Installation and assets

下载 `Music-Workbench-0.2.0.dev21-Setup-x64.exe`，核对 `SHA256SUMS.txt`，关闭旧版再安装。基础运行环境、内置音色和跟练已包含；模型需要按需联网下载。工程与模型保存在独立数据目录，升级不要求搬动作品。安装器未签名。

Download Setup-x64.exe, check SHA256SUMS.txt, close the old app and install. Basic runtime, instruments and lesson are bundled. Models download separately. Projects and models use separate data directories. The installer is unsigned.

发布资产包含安装器、源码/ wheel、校验文件、First Sketch 跟练工程、《雨后的街灯》的 WAV/MIDI/MWB 与署名，以及带合成旁白、字幕和章节的入门宣传片。MIDI 只包含可编辑的乐器音符，不能替代完整音频工程。

Assets include Setup, source/wheel, checksums, lesson project, After the Rain WAV/MIDI/MWB and credits, plus a narrated introductory film with subtitles and chapters. MIDI contains editable instrument notes; it is not the full audio project.

## 已验证范围与限制 / Evidence and limits

查看[本版验证记录 / Validation](../dev21-validation.md)。本机验证不等于全新 Windows 或所有显卡均通过。仅在实际测得的设备上报告速度和资源数据；小规模钢琴开发评测不证明所有曲风或训练集独立性。

This is a development preview, not a compatibility guarantee for every PC. Fixed 4/4, up to 32 tracks, eight one-level buses and ten-minute projects. VST hosting, effect-parameter automation, synchronized overdubbing, latency compensation and deep workstation Agent control remain unavailable. Transcription and separation require checking by ear; generated BPM/key conditions are not verified musical facts.

固定 4/4、最多 32 轨、8 条一级总线、10 分钟工程。VST、效果参数自动化、同步叠录、延迟补偿和深度 Agent 操作尚未提供。转录、分轨与生成结果需核对，提示的速度/调性不等于生成一定准确。
