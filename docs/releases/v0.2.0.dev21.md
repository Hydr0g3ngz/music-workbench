## 本版更新 / What's new

- 钢琴录音可用 Transkun 转成可编辑音符，试听后加入乐器轨。Transcribe piano into editable notes with Transkun.
- 音符太密时，可按音区、力度和起音整理声部，先试听再应用。Preview note-part simplification before applying it.
- 相关片段可成组复制、移动，批量调整音量和淡入淡出。Group clips and adjust gain/fades together.
- 总线、发送和共享混响让多条音轨更容易一起调整。Use buses, sends and shared reverb.
- 修复了保存冲突、任务按钮刷新和采用结果时的编辑问题。More reliable saves, task controls and result adoption.

## 更新与要求 / Updating and requirements

更新前保存工程并关闭软件，建议导出 `.mwb` 备份。作品和模型独立保存。安装器目前未签名；AI 工具在软件中按需下载，硬件要求各不相同。当前支持固定 4/4、最多 32 轨、8 条总线和 10 分钟工程。VST、同步叠录和深度 Agent 操作尚未提供。

Save and close before updating; keep an MWB backup. Projects/models are separate from program files. The installer is unsigned. Optional AI tools download in the app and have different hardware requirements. Fixed 4/4, up to 32 tracks, eight buses and ten minutes; no VST, synchronized overdubbing or deep Agent control yet.
