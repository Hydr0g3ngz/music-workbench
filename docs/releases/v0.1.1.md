# Music Studio v0.1.1 · Preview / 预览版

> 历史版本 / Historical build：本页描述拆分前的 Music Studio/Next/Create，非当前 Workbench 安装说明。See the [current release](https://github.com/Hydr0g3ngz/music-workbench/releases/tag/v0.2.0.dev14) for the Windows installer and supported features.

First published preview. Includes the demo PCM-cache fix verified during release acceptance.
首个实际发布的预览版，包含发布验收发现的示例 PCM 缓存修复；0.1.0 构建已停止，未发布。

Unfold a song into vocals, backing, timed lyrics, vocal melody MIDI, chords and beats.
本地拆解歌曲，在同一条时间轴试听人声、伴奏、歌词、主旋律、和弦与节拍。

## Download / 下载

- **Windows:** `Music-Studio-0.1.1-Windows.zip`. Extract and double-click `Start-Music-Studio.cmd`.
- **Python package:** `music_studio_local-0.1.1-py3-none-any.whl`.
- **Source:** `music_studio_local-0.1.1.tar.gz`.
- Verify file integrity against `SHA256SUMS.txt`.

Windows 用户解压 ZIP 后双击启动；Python 用户可安装 wheel；源码包用于开发。
使用 `Get-FileHash -Algorithm SHA256 <file>` 对照校验文件。

**Requires Python 3.11 or 3.12.** Initial startup downloads Python dependencies.
The ZIP is a source+wheel distribution, not a standalone EXE. No Python runtime,
CUDA toolkit, private recordings, benchmark audio or neural weights are bundled.

**需预先安装 Python 3.11 或 3.12**，首次启动联网安装依赖。ZIP 包含源码与 wheel，
不是独立 EXE；不包含 Python、CUDA、私人歌曲、测试集音频或神经模型权重。

Choose **Try the demo / 加载示例歌曲** for a credited 45-second precomputed example:
immediate timeline exploration, original/vocal/backing playback, lyric correction,
sing along and export, without model downloads. Switch 中文 / English at top right.

To analyze your own songs, run:

```powershell
.\scripts\setup.ps1 -Mode full -Device cuda -DownloadModels
# CPU: replace cuda with cpu / 无 NVIDIA 显卡时把 cuda 改为 cpu
.\scripts\launch.ps1
```

## Included / 本版内容

Bilingual UI and documentation; stable lazy-loaded playback; editable lyric text;
review workflow and result versions; sing-along mode; recoverable project deletion;
43-case reproducible benchmark. See [README](https://github.com/Hydr0g3ngz/music-studio#readme).

中英界面与说明、稳定按需载入的试听、歌词改字与核对、结果版本与候选比较、跟唱视图、
歌曲删除恢复，以及有来源和哈希的 43 例评测。

## Known limits / 已知限制

- Machine lyrics/timing/notes/chords need listening review. Gray text has line timing only.
- Main inference target: NVIDIA 8GB VRAM. CPU is slower; macOS/AMD/Intel GPU inference has not been validated.
- Qwen recognition requires a separate optional environment; dual timing guides are optional and can worsen timing tails.
- Long songs use more browser memory. There is no full notation or multi-instrument editor.

识别结果需试听核对，灰色文字仅有句级时间。主要推理验证环境为 NVIDIA 8GB；
CPU 较慢，macOS/AMD/Intel GPU 尚未验证。Qwen 需可选独立环境，双模型对齐可能扩大尾部误差。
长歌曲占用更多浏览器内存；暂不提供完整谱面或多乐器编辑。
