# v0.2.0.dev19 — 专注创作的入口 / A creation-focused entry

Music Workbench 的首页和启动入口统一面向创作、编排、录音和混音。整曲歌词、旋律、和弦与节拍分析由独立的 [Music Studio](https://github.com/Hydr0g3ngz/music-studio) 维护。

Music Workbench's home and launch entries focus on creation, arrangement, recording and mixing. Full-song analysis remains in the independent [Music Studio](https://github.com/Hydr0g3ngz/music-studio) product.

- **首页 / Home:** 根地址与 `index.html` 打开创作首页。Root and `index.html` open creation home.
- **旧书签 / Older bookmarks:** `?project=` 保留素材 ID 并转到素材编辑器；`?session=` 打开多轨工程。Asset and arrangement IDs retain their distinct destinations.
- **素材编辑 / Asset editing:** 修正产品品牌和模型说明链接；从任务详情可返回原编曲工程。Correct branding/setup links and return from task details to the originating arrangement.
- **源码启动 / Source startup:** `scripts/launch-workbench.ps1` 默认使用 Workbench 工作区，公开 CLI 只描述创作命令。The source launcher uses the Workbench workspace; the public CLI describes creation commands.
- **数据 / Data:** 默认普通模型路径改为 Workbench 自己的 AI 目录；显式路径继续有效，不自动迁移其他产品数据。The default unmanaged model directory belongs to Workbench; explicit paths remain supported, with no automatic migration from the other product.
- **兼容 / Compatibility:** 既有工程格式、API、历史与 MWB 保持兼容。Existing formats, APIs, history and portable projects remain compatible.

素材编辑器的修改不会自动覆盖多轨编排，处理结果仍需明确采用。内部 Python 命名空间与部分隐藏文件名沿用历史名称；见[产品与数据边界](../product-boundaries.md)。本版没有新增模型或宣称识别质量提高。

Asset edits do not automatically overwrite arrangements; adoption remains explicit. The internal Python namespace and some hidden filenames retain historical names for compatibility. See [product and data boundaries](../product-boundaries.md). This version adds no model and makes no recognition-quality improvement claim.
