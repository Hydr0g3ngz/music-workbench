# Music Studio Create · 音乐制作预览

> 历史版本 / Historical build：本页描述拆分前的 Music Studio/Next/Create，非当前 Workbench 安装说明。See the [current release](https://github.com/Hydr0g3ngz/music-workbench/releases/tag/v0.2.0.dev14) for the Windows installer and supported features.

Start with a musical idea, arrange it and export a mix. This preview adds a dedicated
multitrack workspace while retaining the classic analyzer and Next audio-processing UI.

- Unified playback, clip/track editing, undo/redo, saved sessions, mixer and WAV/MIDI export.
- Three sampled instruments, three synth sounds, 23 CC0 samples and eight editable GMD grooves with exportable credits.
- MIDI import with sustain/tempo handling and editable note pitch, timing and velocity.
- Optional ACE-Step 1.5 Turbo: generate a draft, audition it, explicitly add it as a track.
- Pinned isolated setup, Windows checkpoint-memory fix, diagnostics and bilingual guides.

**Windows:** install Python 3.11/3.12, extract the ZIP into a new writable folder, then run
`Start-Music-Studio-Create.cmd`. Factory instruments and arrangement do not require neural
models. For optional generation, run `py -3.12 scripts/setup_ace.py` explicitly. This requires
NVIDIA CUDA; 12s and 20s instrumentals passed on an RTX 4070 Laptop 8GB / 32GB RAM. See the
resource report before downloading. Linux generation and other GPU/RAM profiles remain unverified.

The ZIP is source + wheel, not a standalone EXE. Python, CUDA and neural weights are not
bundled. Effects chains, recording, automation, modern music separation/transcription and
full creation acceptance remain incomplete. Vocal/lyric and long-generation quality remain
unmeasured; a successful draft is not a quality benchmark. Use an independent workspace
when trying this version; older releases and workspaces remain available.

中文：这版把采样乐器、鼓点、MIDI 和多轨编排连到同一工程，可混音、撤销和导出。
可选安装 ACE-Step 本地生成，先试听再加入轨道。双击 **Start-Music-Studio-Create.cmd**；
基础制作无需神经模型。生成需要额外安装、NVIDIA CUDA 与足够系统内存，完整实测含失败记录。
该版本尚不含后续加入的 EQ、压缩、混响、限制器和混音预设。
经典版与原 Next 入口继续保留，旧歌曲不自动迁移。

Validation: 118 Python checks, 32 Node checks, Ruff, installed-wheel validation and real
browser flows. See guides for scope and hardware limitations.
