# v0.2.0.dev20 — 可编辑 AI 创作与混音 / Editable AI creation and mixing

本地开发预览，2026-10-17。GitHub 公开安装器仍为 dev14；本版本尚未公开发布。

Local development preview, 2026-10-17. The public GitHub installer remains dev14; dev20 is not yet published.

- **编排 / Arrangement**：Shift 多选、片段分组、成组拖动/复制/删除、独立副本与逐次撤销。[指南 / Guide](../groups-and-routing.md)
- **音符 / Notes**：Basic Pitch 0.4.0 ONNX CPU 自动工具包；可调阈值，所选片段 → 试听 → 加入乐器轨 → 钢琴卷帘 → MIDI/WAV。[指南 / Guide](../polyphonic-notes.md)
- **混音 / Mix**：最多 8 条一级总线、轨道输出、推子后发送、100% 湿声共享混响、总线电平/声像/EQ/压缩/混响/旁路；实时与离线路由一致。
- **修复 / Fixes**：钢琴卷帘双击删除、快速分组操作的撤销粒度、总线名称更新后的路由标签；使用标准竖向推子样式。Piano deletion, group history, route labels and standard vertical faders.
- **实例 / Example**：《窗灯》从空工程制作 32 小节，WAV/MIDI/MWB 导出及恢复验证。[制作记录 / Case study](../creations/windowlight.md)

Basic Pitch 是轻量基线，不承诺复杂混音的完整准确扒谱。五首 GuitarSet 开发集仅比较参数；训练数据重叠可能存在。Transkun 未接入。GPU/安装验证仍主要覆盖一台 Windows 11 / RTX 4070 Laptop；未覆盖所有 GPU、全新电脑或目标用户试用。

Basic Pitch is a lightweight baseline, not guaranteed full-score transcription. The five-case GuitarSet parameter comparison may overlap model training data. Transkun is not integrated. Hardware evidence remains primarily one Windows 11 / RTX 4070 Laptop machine.

打开旧工程会按默认值兼容新增字段；保存后的 dev20 工程可能无法在旧版恢复，升级前保留 MWB 备份。模型按需下载，不内置于安装器。VST、效果参数自动化、同步叠录、延迟补偿及深度 Agent 操作仍未提供。

Older projects load with default fields. After saving in dev20, older builds may reject new fields; retain MWB backups. Models download separately. VST, FX automation, synchronized overdubbing, latency compensation and deep Agent operation remain unavailable.
