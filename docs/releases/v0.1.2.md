# Music Studio v0.1.2 · Preview / 预览版

> 历史版本 / Historical build：本页描述拆分前的 Music Studio/Next/Create，非当前 Workbench 安装说明。See the [current release](https://github.com/Hydr0g3ngz/music-workbench/releases/tag/v0.2.0.dev14) for the Windows installer and supported features.

Fixes the Windows shortcut failing at lyric recognition when Qwen is selected.
修复双击启动后选择 Qwen，在歌词识别阶段报错的问题。

- The launcher automatically connects the separate environment installed by `scripts/setup_lyrics.ps1`.
- A custom environment can be selected with `scripts/launch.ps1 -LyricsPython 'C:\path\to\python.exe'`.
- Uninstalled recognizers are disabled in the bilingual UI. The API checks dependencies before doing work.
- Older running servers show restart instructions; existing songs, audio and result versions are preserved.

启动器自动连接已安装的歌词独立环境；未安装的识别模式在中英界面中停用。
后台提前检查依赖，避免分离音轨后才失败。正在运行的旧后台需重启，原有歌曲和结果均保留。

## Download / 下载

Windows: **Music-Studio-0.1.2-Windows.zip**. Extract and double-click `Start-Music-Studio.cmd`.
Python: `music_studio_local-0.1.2-py3-none-any.whl`. Source: `music_studio_local-0.1.2.tar.gz`.
Verify downloads against `SHA256SUMS.txt`.

Requires **Python 3.11 or 3.12**. First startup installs preview dependencies.
The 45-second licensed demo works without neural weights. Analysis of your own songs needs:

```powershell
.\scripts\setup.ps1 -Mode full -Device cuda -DownloadModels
# CPU: replace cuda with cpu / 无 NVIDIA 显卡时把 cuda 改为 cpu
# Optional Qwen / 可选 Qwen：
.\scripts\setup_lyrics.ps1
.\Start-Music-Studio.cmd
```

After updating or installing models, press **Ctrl+C** in the old startup console and relaunch.
Use the URL opened by the launcher; an older browser tab may still point to an old server.

升级或安装模型后，请在原启动窗口按 **Ctrl+C**，再双击启动。
使用启动器新打开的地址，旧标签页可能仍连接旧后台。

The ZIP does not bundle Python, CUDA or models. Lyrics, timing, melody and chords are estimates;
this patch improves runtime setup, with no new accuracy claim. See the
[README](https://github.com/Hydr0g3ngz/music-studio#readme) and
[validation](https://github.com/Hydr0g3ngz/music-studio/blob/main/docs/release-validation.md).

ZIP 不含 Python、CUDA 和模型权重；本次修复启动与环境检查，不声称识别准确率提升。
