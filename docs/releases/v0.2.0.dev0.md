# Music Studio Next v0.2.0.dev0 · Development preview / 开发预览

> 历史版本 / Historical build：本页描述拆分前的 Music Studio/Next/Create，非当前 Workbench 安装说明。See the [current release](https://github.com/Hydr0g3ngz/music-workbench/releases/tag/v0.2.0.dev14) for the Windows installer and supported features.

An independent local audio workbench, with licensed demo audio, reversible editing,
on-demand model tasks, editable transcripts and shared MCP/Codex tools.
This prerelease does not replace [v0.1.2](https://github.com/Hydr0g3ngz/music-studio/releases/tag/v0.1.2).

独立的本地音频工作台开发预览：可撤销剪辑、按需模型任务、转写改字，与 MCP / Codex 共用状态。
旧版 v0.1.2 继续保留；Next 使用独立环境、工作区与端口，不自动迁移原歌曲或识别版本。

## Try it / 启动

Download **Music-Studio-0.2.0.dev0-Windows.zip**, extract it, and double-click
**Start-Music-Studio-Next.cmd**. Requires **Python 3.11 or 3.12**. First start installs
the separate editing environment; neural models are optional and not included.
This is a source + wheel preview, not a standalone Windows EXE.

下载并解压 Windows ZIP，双击 **Start-Music-Studio-Next.cmd**。需要 Python 3.11 / 3.12；
首次安装基础依赖需要网络，剪辑与授权示例不需要下载神经模型。本包不是独立 EXE。
经典入口 **Start-Music-Studio.cmd** 也保留。

For local AI tasks / 启用本地推理：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\setup-next-models.ps1 -Device cuda
# CPU: use -Device cpu. Restart Next after setup / 无 NVIDIA 显卡可改用 cpu，安装后重启 Next。
```

Qwen needs its optional isolated lyrics runtime. See the bilingual
[model setup guide](https://github.com/Hydr0g3ngz/music-studio/blob/v0.2.0.dev0/docs/next-models.md).
Validate downloads with `SHA256SUMS.txt`. Models are downloaded separately from official sources.

## Available / 当前功能

- Waveform selection, trim, gain, fades, stereo balance, reverse, stem mixing, undo/redo and WAV export.
- Seven capability entries: levels, Demucs stems, Whisper/Qwen transcripts, two CREPE decoders and beats.
- Persistent serial task queue, isolated imports and inference, cancellation, pinned assets and diagnostics.
- Transcript corrections as new versions, with TXT/LRC/SRT downloads and original recognition retained.
- Fifteen shared tools for UI, real MCP clients and an experimental installed-Codex bridge.
- Chinese/English interface and documentation. Audio editing works without a model or account.

波形选区、剪辑、增益、淡入淡出、平衡、倒放、分轨混音、撤销/重做与 WAV 导出。
7 个能力入口共用队列，结果可试听/下载，转写支持逐行改字。任务不会自动采用结果或重载试听。
Codex 需已有 CLI 和登录；音频处理在本机，对话与必要工具信息会发送给 Codex 服务。

## Evidence and limits / 验证与边界

Real model tasks completed on a licensed 15-second excerpt; browser checks include real
45-second separation, transcription, text corrections and continuous playback through task completion.
The frozen melody follow-up tests 40 vocadito and 12 GTS clips, with separate human annotators.
Rest-preserving decoding improves vocadito but regresses on GTS, so it remains optional and
the classic default is retained. MIDI roundtrip timing is checked separately from note accuracy.

真实模型与浏览器流程已验证；基准同时保留进步和退步，不把音符合成音色当作识别质量提升。
旋律仍是单旋律估计。模型任务目前每段最多 600 秒；长录音流式处理、LUFS、语音降噪、
语义分离和生成式声音仍在开发计划中，不属于当前可用功能。

Model weights are not bundled. GPU measurements do not guarantee every model/recording fits
8GB. The repository includes source, licenses, per-case scores and reproducible evaluation scripts.
