# Music Studio v0.2.0.dev4 · Mix your drafts / 把草稿混成作品

> 历史版本 / Historical build：本页描述拆分前的 Music Studio/Next/Create，非当前 Workbench 安装说明。See the [current release](https://github.com/Hydr0g3ngz/music-workbench/releases/tag/v0.2.0.dev14) for the Windows installer and supported features.

Continue the idea → draft → arrangement → mix → export workflow with live track EQ,
compression and reverb, four editable presets, A/B bypass and optional master sample-peak limiting.
Settings autosave, undo and reopen with the session. WAV includes effects and reverb tails.
Live tweaks and language changes keep existing audio sources running.

本版补上混音底座：实时三段 EQ、压缩、混响，四组可修改预设、原声 A/B、可选主输出采样峰值限制。
效果参数随工程自动保存、可撤销；导出包含尾音。旧工程效果默认关闭，经典版与 Next 保留。

## Start / 启动

Install Python 3.11/3.12, extract the Windows ZIP and run `Start-Music-Studio-Create.cmd`.
首次启动会安装独立 Python 环境和依赖；基础制作与效果器无需神经模型。
The ZIP contains source and a wheel, **not a standalone EXE**. Python, CUDA and model weights are not bundled.

## Boundaries / 范围

Fixed-order built-in effects; no buses/sends, automation, recording or VST yet. The limiter is
sample-peak, **not true peak**. Seeking/resuming/looping rebuilds effect state; initial tails may differ
from uninterrupted playback. Live tweaks are not recorded automation. Presets are starting points,
not AI mastering. A/B does not automatically loudness-match.

限制器不是 True Peak；大幅限制可能失真。定位/恢复/循环会重建效果状态。可重排链、总线/发送、
自动化、录音与插件尚待实现。先备份工作区，再关闭使用同一工作区的旧后台并启动新版本。
Existing audio is retained; never run two services against one workspace.
