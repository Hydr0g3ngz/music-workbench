# Music Studio Next · Speech cleanup / 语音清理

> 历史版本 / Historical build：本页描述拆分前的 Music Studio/Next/Create，非当前 Workbench 安装说明。See the [current release](https://github.com/Hydr0g3ngz/music-workbench/releases/tag/v0.2.0.dev14) for the Windows installer and supported features.

Clean a recording, compare it at matched loudness, and keep the result only when you choose.
The classic song analyzer and older workspaces remain separate.

- CPU speech cleanup: DPDFNet2 48 kHz and experimental GTCRN, with explicit model installation.
- Integrated LUFS / true peak / LRA and static-gain normalization with peak constraints.
- Synchronized A/B, immutable input/output assets, editable previews, undo/redo and WAV export.
- Sixteen shared UI/MCP/Codex tools; bilingual interface, setup and evaluation reports.
- Credited CC BY 4.0 noisy speech demo and 32 paired regression cases; per-case failures retained.
- Launch checks for older running Next versions; unsupported new controls stay hidden on old APIs.

**Windows:** install Python 3.11/3.12, extract the ZIP into a new writable folder and double-click
`Start-Music-Studio-Next.cmd`. Initial setup downloads dependencies, including the CPU runtime.
Choose the speech demo, then **Clearer speech** to explicitly download about 10.11 MiB of
DPDFNet weights. No Torch, GPU or Codex account is needed for basic cleanup/editing.
This is a source + wheel package, not a standalone EXE; Python and weights are not bundled.

When upgrading an existing Next workspace, close its older backend before launching, or use
an independent folder/workspace/port. Do not overwrite the classic `outputs/ui` workspace.

The 16-pair follow-up showed DPDFNet mean SI-SDR +7.029 dB and STOI +0.01265, with five STOI
regressions. Only two English speakers from one domain were tested; these results do not
establish Chinese, music or arbitrary-recording quality. Listen before adopting. LUFS defaults
are editable starting points, not a compliance guarantee. Embedded Codex requires an existing
CLI/login; conversations and read text/tool results use its service, without implicit audio upload.

中文：这版把“讲话更清楚 → 等响度对比 → 满意后采用”做成可撤销流程。新增两种 CPU 降噪、
响度测量与统一、同位置 A/B、16 个共享 Agent 工具，以及双语说明和授权示例。

安装 Python 3.11/3.12，将 ZIP 解压到新目录，双击 **Start-Music-Studio-Next.cmd**。
首次联网安装依赖；在语音清理面板明确安装约 10.11 MiB 的 DPDFNet 权重后运行。
基础清理不需要显卡、Torch 或 Codex。旧版启动器与数据保留；升级旧 Next 前关闭其后台，
或使用独立工作区与端口。ZIP 不是独立 EXE，不包含 Python 或权重。

模型可能改变人声、环境声与音乐。follow-up 的 DPDFNet 平均指标改善，但 16 条中仍有 5 条
STOI 退步；测试仅含两位英语说话人。报告保留失败样本，不能把结果当所有音频的质量保证。
