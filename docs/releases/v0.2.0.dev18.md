# v0.2.0.dev18 — 片段处理与更快的连续任务 / Selected clips and faster consecutive tasks

选中需要处理的音频片段再运行工具。模型现在只接收这段音频；结果从片段内 0 秒开始，采用分轨、旋律和变速结果时保留工程位置。旧任务继续按原范围使用。

Select the audio clip you want to process. Tools now receive only that window. Exports start at zero within the clip; stem, melody and time/pitch adoption retain its session position. Older tasks keep their original timeline mapping.

- **连续处理更快 / Faster consecutive tasks:** RoFormer、Demucs 和 Whisper 在相同设置下可复用模型；空闲 30 秒或切换、取消、关闭、等待生成任务时释放。Same-setting tasks can reuse one model; idle expiry, tool changes, cancellation, shutdown and waiting generation release it.
- **时间对应一致 / Consistent timing:** 修正裁剪后结果试听、A/B 比较、MIDI 回填与对拍分析的时间起点。Cropped auditions, A/B windows, melody adoption and beat-fit reports use the correct time origin.
- **改字时试听原片段 / Audition while correcting:** 歌词编辑器提供提交时音频的播放器。The transcript editor can play the captured task input.
- **可复现记录 / Reproducible inputs:** 固定源帧范围、输入哈希和结果采用记录；相同片段产生相同输入哈希。Source frame bounds and hashes are retained; repeated selections produce identical pinned inputs.

本轮在 RTX 4070 Laptop 8 GB 上完成真实分轨、转写、旋律和变速流程验证。单次实测中，12 秒片段的 RoFormer 模型阶段为首次 12.3 秒、复用后 3.5 秒。首次环境检查和启动另计；这些数值不代表所有设备的速度，也不表示识别质量提高。

Real separation, transcription, melody and time/pitch workflows passed on an RTX 4070 Laptop 8 GB. In one paired run, RoFormer took 12.3 seconds initially and 3.5 seconds with model reuse on the same 12-second input. Environment checks and startup add time. This is not a universal performance or quality claim.

Qwen 保持识别器与对齐器顺序加载，尚不复用模型。短片段可能丢失音乐和语言上下文，请试听核对。

Qwen keeps sequential recognizer/aligner loading without model reuse. Short windows can lose musical and language context; audition the result.
