# 计划中的功能 / Planned features

[当前功能 / Available now](../README.md) · [提出建议 / Suggest a feature](https://github.com/Hydr0g3ngz/music-workbench/issues)

Music Workbench 的创作流程是：导入、录音或生成 → 试听和编辑 → 组织段落 → 混音 → 保存和分享。以下功能仍在计划中，没有承诺的发布日期。

The workflow is import, record or generate → listen and edit → arrange → mix → save and share. The items below are planned and have no committed release date.

| 方向 / Area | 希望改善的体验 / Intended improvement |
| --- | --- |
| 安装与硬件 / Setup and hardware | 扩展 Windows、GPU 和受限网络下的兼容性；减少模型加载等待 / Broader compatibility and shorter model startup |
| 音频适配 / Timing | 变速音乐的局部修正与更可靠的强拍辅助 / Local timing edits and downbeat assistance |
| 候选与重绘 / Candidates | 更容易管理候选、试听接缝、比较段落变奏 / Easier candidate and join comparison |
| 混音与录音 / Mixing and recording | 效果参数自动化、VST、同步叠录和延迟补偿 / FX automation, VST, synchronized overdubbing and latency compensation |
| 更多声音工具 / Sound tools | 按实用性和许可逐步扩展修复、音色转换、音效生成和检索 / Restoration, timbre, effects and search where practical |
| Agent | 在可检查、可撤销的工程操作上增加深度智能体控制 / Reviewable, undoable agent control of project operations |

当前可用的总线、发送、Basic Pitch、Transkun 和音符整理见 [功能指南](README.md)。尚未接入的模型见 [候选列表](local-model-candidates.md)，不能在当前软件中直接使用。

Buses, sends, Basic Pitch, Transkun and note simplification are available now; see the [guides](README.en.md). [Research candidates](local-model-candidates.en.md) are separate from supported tools.
