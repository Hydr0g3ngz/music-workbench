# 成组编排、总线与发送

[English](groups-and-routing.en.md) · [文档](README.md)

适用于 dev20 源码与本地安装包。GitHub 公开 dev14 安装器不包含这些新增功能。

## 从八小节发展作品

1. 在时间线上 Shift 点击多个片段，或打开 **编排 / 路由 → 成组编排 → 选择所有片段**。
2. 点击 **组成一组**。此后点击任一组员会一起选择；拖动、复制和删除作用于整组。
3. 在 **放到第几小节** 输入目标，例如 9，选择 **复制到这里**。各片段的相对位置、源裁切、音符、音量曲线与淡变保留。
4. 继续复制到第 17、25 小节，形成 32 小节；每个副本有独立分组，可分别修改。需要单独编辑时先 **解除分组**。

**选择当前段落** 使用播放头所在的段落，仅选择完整位于该段落内的片段；它不会裁切跨界片段。段落范围复制仍在段落工具中。成组操作单独保存为历史步骤，可撤销/重做。工程上限仍为 32 轨、每轨 128 片段、总计 8192 音符和 10 分钟。

## 分组总线

打开 **编排 / 路由 → 总线与发送**，添加 **分组总线**，命名后把相关轨道的 **输出** 改为该总线。例如钢琴与马林巴都进入 Piano family；在总线统一调整音量、声像、EQ、压缩或混响。

路由顺序：轨道效果 → 轨道推子/声像 → 输出总线 → 总线效果与推子 → Master。最多 8 条总线；总线直接进入 Master，暂不支持总线互送、嵌套或反馈。

## 共享混响

添加 **共享混响** 会创建 100% 湿声总线。在每条轨道下勾选向该总线发送，并从较小发送量开始，例如 −20 dB。原干声仍走轨道输出，发送只添加空间感。降低轨道推子也会降低发送量，因为发送位于推子之后。

普通总线混响也可设置干湿比例；用作共享混响时保持 1.00，避免额外复制干声。将同一总线同时设为输出和发送会相加，通常没有必要。

播放时可调整现有发送量/开关、总线推子和效果，无需重新下载音频。更改轨道输出或首次建立发送会暂停播放以重建路由，再按播放继续。

轨道 Solo 先选择声源；总线 Solo 只让被 Solo 的总线通过，并关闭直接 Master 路径。Mute 优先于 Solo。移除总线后，其轨道恢复输出到 Master，相关发送被移除；可撤销恢复。

## 保存与导出

WAV 包含总线效果、发送与混响尾音。实时和离线渲染共享效果算法和路由顺序；设备采样率、分块与浮点舍入可能产生差异，不承诺逐样本相同。MIDI 保存音符，不包含音频总线和效果；用 `.mwb` 保留完整可编辑工程。dev20 工程应使用 dev20 或更新版本打开，旧版本可能拒绝新增字段。
