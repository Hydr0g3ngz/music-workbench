# 把 AI 音符变成自己的声部

[English](note-editing.en.md) · [模型选择](models.md)

先选中音频片段，在 AI 模型中运行 **Basic Pitch**（单乐器多音、CPU）或 **Transkun**（钢琴专用）。完成后试听音符合成结果，再点 **音符加入乐器轨**。录音保留，新增的乐器轨可以换音色、编辑音高、时值与力度。

## 音符太密时

双击 MIDI 片段打开钢琴卷帘，点击 **整理声部**。用最低/最高 MIDI 音高限定音区，用最小力度筛掉较弱的音。还可在相近的起音中，只留下最高音或最低音。起音容差的单位是拍；它不移动音符，也不缩短持续时间。

**高音回声预设** 是一个起点：MIDI 60–108、最小力度 45、相近起音保留最高音。根据素材收窄音区，例如只保留 60–84。先点 **试听整理后的声部**；满意再应用，不满意可以调整或关闭。应用支持撤销。

这是编曲规则，不是模型自动纠错。保留下来的音也可能是误检，删掉的音也可能真实存在；模型力度是估计值。需要精确乐谱时仍须核对录音。复杂混音应先分轨，Transkun 不适用于混合乐器。

## 批量调整过渡

Shift 点击选择片段，打开 **编排 / 路由 → 成组编排**。可以为所选片段统一设置音量或淡入/淡出。值会应用到每个片段；若某个片段太短、淡变长度无效，整次操作不执行。每次操作独立保存，可撤销。

分组副本可独立修改。先复制短句，再让不同段落有不同分工：开头留白、中间回应、第三段换质感、结尾降低音量并渐弱。参见[《雨后的街灯》](creations/after-the-rain.md)。
