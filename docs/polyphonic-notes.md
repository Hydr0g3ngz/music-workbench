# 把独奏乐器音频变成可编辑音符

[English](polyphonic-notes.en.md) · [模型目录](models.md)

dev20 新增 **Basic Pitch 0.4.0 ONNX**：从单件乐器录音估计重叠音符，生成 MIDI，再用乐器音色演奏和修改。它是轻量基线，不是复杂混音的自动完整配器或保证准确的扒谱工具。

## 安装与使用

1. 首页 **AI 工具管理** 安装 **多音音符**。Windows x64，CPU 即可，预计下载 150–350 MB，预留 2 GB。无需系统 Python 或显卡。
2. 导入钢琴、吉他等独奏录音，选中需要处理的音频片段。复杂混音先分轨；模型不负责辨认并分离各乐器。
3. 在 **AI 模型 → 独奏乐器 → 多音 MIDI** 运行。只处理选中的源裁切范围，结果保留来源与时间起点。
4. 先试听合成音符，选择 **音符加入乐器轨**。打开钢琴卷帘修改音高、位置、时值和力度，或全选后量化、换音色；双击音符删除。
5. 导出 MIDI 保存音符，或用 WAV 听当前乐器与混音。`.mwb` 包含音频和可编辑音符，可恢复继续制作。

识别任务会保留原音频；采用可撤销。音符力度来自模型幅度估计，不能视为原演奏力度的精确还原；弯音不导入钢琴卷帘。过密结果可先只截取短句处理。

## 参数怎么调

| 参数 | 默认 | 调整方向 |
| --- | --- | --- |
| 起音阈值 | 0.50 | 提高通常减少误检，也可能漏掉弱音 |
| 持续阈值 | 0.30 | 提高可能缩短持续音；需要对照试听 |
| 最短音符 | 127.7 ms | 提高过滤短杂音，也会漏掉快速演奏 |

不要把降低阈值当作提高准确率。五首冻结 GuitarSet 吉他伴奏的开发评测中，默认配置起音 F1 **0.672**，含止音 F1 **0.333**；保守配置分别为 0.656 / 0.315，敏感配置为 0.604 / 0.323。因而保留默认设置。Basic Pitch 训练使用过 GuitarSet，存在数据重叠可能；这不是独立测试集排名，也未测力度准确率。协议与全部数值见[评测记录](polyphony-benchmark.md)。

16 秒 AI 钢琴在本机的任务推理约 **6.63 秒**，完整调用约 **11.59 秒**；不代表所有 CPU。ONNX 权重约 225 KiB，完整运行环境还包含音频解码与科学计算依赖。该工具包不安装 TensorFlow、Torch，不宣称 CUDA 后端。首次运行可能有导入/JIT 开销。

## 实现与许可

官方 Basic Pitch wheel 的源码与 ONNX 权重单独提取，校验固定 SHA-256；不安装会引入 TensorFlow 依赖的发行元数据。环境与其他模型隔离，安装验证运行真实离线推理。损坏时在 AI 工具管理选择检查/修复。

代码与权重 Apache-2.0：[Spotify Basic Pitch](https://github.com/spotify/basic-pitch)。ONNX Runtime 使用 MIT 许可。版本、哈希及评测脚本随仓库保存；权重按需下载，不随安装器内置。Transkun 仍是未接入候选。
