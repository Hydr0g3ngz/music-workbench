# 打开 Music Workbench / Open Music Workbench

安装后，从桌面或开始菜单打开 **Music Workbench**。首页选择 **跟着做出第一段音乐**；需要打开自己的声音时，选择导入素材。

After installation, open Music Workbench from the desktop or Start menu. Start with **Make your first musical sketch**, or import your own sound.
